# PKT Portal

Cổng ứng dụng chung cho Phòng Kỹ thuật.

## Cấu trúc
- index.html: trang chủ
- tien-do/index.html: Quản lý tiến độ
- hao-hut/index.html: Quản lý số lượng & hao hụt
- ptd/index.html: Quản lý phương tiện đo
- assets/css/portal.css
- assets/js/portal.js

## Đưa lên GitHub Pages
1. Tạo repository.
2. Upload toàn bộ nội dung trong thư mục này.
3. Settings → Pages.
4. Deploy from a branch.
5. Chọn main và /(root).
6. Save.

Các KPI trên trang chủ hiện là dữ liệu minh họa. Sau này có thể nối JSON/API để lấy số liệu tự động từ từng module.
